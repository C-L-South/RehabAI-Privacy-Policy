App preview: exercise setup and movement feedback

By RehabAI · September 28, 2026

The RehabAI preview shows two parts of the exercise experience: setting up an exercise and viewing movement feedback. Here is what is visible in the screens shared on this website.

What does the exercise setup screen show?

The setup preview displays a Cobra Stretch exercise card, a Start Exercise button, and a cue to position the left side of the body toward the camera. A duration control is set to 30 seconds, with plus and minus buttons. An Instructions Read Aloud option appears below it.

The bottom navigation shows Home, Exercise, Progress, and Settings. These details give visitors a view of the interface before a download link is available.

What does the movement feedback screen show?

The second preview shows an exercise image with connected body markers, a 15/20 counter, and a progress bar. It illustrates how movement information is presented visually in the preview.

A screenshot does not establish tracking accuracy, clinical effectiveness, or which features will be included in a public release. This post describes the interface shown, rather than announcing a tested app version.

Can I download RehabAI yet?

The website currently says “Coming soon” and does not provide a download link. Visit the app page for the current availability notice.
